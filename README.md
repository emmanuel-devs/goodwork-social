# Goodwork Social

A premium, editorial-style concept website for a social media agency. Built with Next.js, React, TypeScript and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Booking integration

Set `NEXT_PUBLIC_GHL_BOOKING_URL` in your deployment environment to the agency's GoHighLevel booking URL. Until supplied, booking links point to the on-page contact section.

## Notes

- The sample work is explicitly labelled as concept work. It does not claim client engagements or verified performance results.
- Replace concept photography and copy with approved agency assets before production use.
- Responsive styling, keyboard-accessible links, semantic sections and reduced-motion preferences are included.
